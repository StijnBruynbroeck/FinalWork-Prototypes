1.1 AssemblyAI (Cloud Speech-to-Text — Legacy)

    Gebruikt model: ggml-base.bin

    Doel: Lokaal draaien van large language models voor AI-beoordeling
    Website: https://ollama.ai
    GitHub: https://github.com/ollama/ollama
    Docs: https://github.com/ollama/ollama/tree/main/docs
    Gebruikte modellen:
      - llama3:latest -> https://ollama.com/library/llama3
      - phi3:mini     -> https://ollama.com/library/phi3

5. DESIGN PATTERNS & ALGORITMES
----------------------------------------

5.1 State Pattern
    - TerminalHacker.cs: TerminalFase (Inactief, Boot, HackMinigame, etc.)
    - EnemyAI.cs: EnemyState (Roam, Chase, Investigate)
    - NeuroFilterAI.cs: Patrol vs Investigate

5.2 Observer Pattern (Events)
    - AudioEventSystem.cs: Static event OnSoundEmitted
    - HackMinigame.cs: OnHackSuccess, OnHackFailed, OnAttemptUsed
    - ZoneData.cs: OnEnter, OnExit events
    - EnemyAI.cs: OnDetected, OnAlert events

5.3 Chain of Responsibility (Routing)
    - VoiceAppController.cs: Spraak routing volgorde:
      1. Deur commando (RouteerNaarDeur)
      2. Terminal hack (RouteerNaarTerminal)
      3. Puzzel (VoiceRiddlePuzzle)
      4. LLM morphing (EvaluatePlausibility)

5.4 Adapter Pattern
    - DoorController.cs: Uniforme interface voor 3 animatiesystemen:
      Legacy Animation, Mecanim Animator, Transform rotatie

5.5 Levenshtein Afstand (Fuzzy String Matching)
    - HackMinigame.cs: VindBesteMatch() met tolerantie
    - TerminalHacker.cs: ZelfdeAls() voor hack stappen
    - Oorspronkelijke paper: Levenshtein, V. I. (1966). "Binary codes capable of correcting deletions, insertions, and reversals". Soviet Physics Doklady, 10(8), 707-710.
    - Link: https://www.mathnet.ru/eng/dan31411

5.6 Fisher-Yates Shuffle
    - HackMinigame.cs: Randomisatie van woordvolgorde
    - Academisch Standaardwerk: Knuth, D. E. (1997). "The Art of Computer Programming, Volume 2: Seminumerical Algorithms" (3rd ed.). Addison-Wesley Professional. (Algoritme P, blz.145).	
    - Oorspronkelijke publicatie: Fisher, R. A., & Yates, F. (1938). "Statistical tables for biological, agricultural and medical research".

5.7 WAV Generator (16-bit PCM)
    - MicrophoneRecorder.cs: Handgeschreven RIFF WAV header + sample conversie
    - Officiële Specificatie: IBM Corporation & Microsoft Corporation (1991). "Multimedia Programming Interface and Data Specifications 1.0".
    - Link: https://www.mmsp.ece.mcgill.ca/Documents/AudioFormats/WAVE/Docs/riffmci.pdf

8. PROJECT-SPECIFIEKE BESTANDEN
----------------------------------------

Alle scripts: Assets/Scripts/
- GroqLLMService.cs      -> LLM client (Ollama)
- GroqAudioService.cs    -> Whisper STT client
- VoiceAppController.cs  -> Hoofdcontroller voice flow
- ObjectSpawner.cs       -> Morphing prefab instantiatie
- TerminalHacker.cs      -> Terminal hack minigame state machine
- HackMinigame.cs        -> Woordraderspel met Levenshtein matching
- DoorController.cs      -> Deur besturing (3 animatiesystemen)
- EnemyAI.cs             -> Vijand AI (NavMesh, suspicion)
- EnemyVision.cs         -> Vijand zicht (view cone, LLM multiplier)
- PlayerMovement.cs      -> First/Third person beweging
- MicrophoneRecorder.cs  -> Microfoon opname + WAV conversie
- AnalyticsManager.cs    -> CSV logging (LLM_Performance_Log.csv)
- ApiCall.cs             -> Legacy AssemblyAI cloud STT
- MicController.cs       -> Microfoon volume monitoring
- AudioEventSystem.cs    -> Static event bus voor geluiden
- FurnitureCounter.cs    -> Meubel telling puzzel
- FurnitureMorphing.cs   -> Legacy UI-gebaseerde morphing
- VoiceRiddlePuzzle.cs   -> LLM-gestuurde meerstaps puzzel
- VoicePuzzle.cs         -> Eenvoudige code-gebaseerde puzzel
- ZoneDetectionManager.cs -> Zone detectie via triggers
- ZoneData.cs            -> Zone metadata component
- TerminalUI.cs          -> Terminal typewriter/color effects
- TerminalDisplay.cs     -> Boot sequence + cursor animatie
- SuspicionUI.cs         -> Suspicion balk UI
- NeuroFilterAI.cs       -> Legacy waypoint AI
- AutomatedTester.cs     -> F12 batch test tool
- GameOverManager.cs     -> Game over + scene reload

Configuratie/Setup bestanden:
